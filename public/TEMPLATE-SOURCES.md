# 合影模板素材说明

更新日期：2026-10-04。当前 CZ 与何一伙伴人物根据用户提供的 `1.jpg`、`2.jpg` 参考表，通过 ChatGPT 内置 `image_gen` 图片生成功能分别重新制作。每张人物的头、颈、肩、手臂与躯干来自同一张连贯图片，替代旧特写头脸与身体拼接版本；没有把旧头脸拼回新素材，也没有对新人物进行局部位移或变形。具体生成模型名没有由工具返回，因此不作推测。

人物素材已预先制作。免费玩家上传头像后，使用浏览器本地人脸定位、分割、等比绘图及签名盖印，不按次调用生图，不消耗玩家的 LibTV 或 ChatGPT 额度。玩家身体、服装变体和蒙版沿用原参考图的本地处理资源；用户原始参考文件保持不变。

## 文件与坐标

素材位于游戏的 `public/assets/templates/`，入口为第 3 版 `manifest.json`。当前伙伴 `cz-generated-v3.webp`、`heyi-generated-v3.webp` 均为 1024 × 1536，采用质量 95 的高质量 WebP 发布副本；原始生成 PNG 另作创作归档。WebP 没有缩放或裁切，alpha 与 PNG 逐像素一致。玩家身体和各类蒙版仍为 384 × 1152 的透明 PNG。路径字段以 `public/` 为根；每一素材的坐标以自身像素为单位。

| 素材 | 内容 |
|---|---|
| `cz-generated-v3.webp`、`heyi-generated-v3.webp` | 根据用户参考预先生成的连贯伙伴人物，头颈肩及躯干来自同一张图片；运行时整图等比放入场景 |
| `cz.png`、`heyi.png` | 保留的历史拼接版本；当前伙伴模板入口不再引用它们 |
| `male-body.png`、`female-body.png` | 移除原头、保留颈部和肩部的身体 |
| `*-body-black.png`、`*-body-cream.png`、`*-body-red.png` | 黑、米白、红三种服装变体 |
| `*-clothing-mask.png` | 白色、按透明度标示的衣服调色区域 |
| `*-skin-mask.png` | 颈部和手臂皮肤区域，含男性手臂纹身的完整皮肤表面 |
| `*-head-erase-mask.png` | 实际从原人物中移除的头发、脸部区域 |

`face` 是额头至下巴、左右脸颊的脸部定位框，不是整头发范围。坐标经过本地人脸检测与人工核对，全部使用素材像素。免费画框为 1024 × 768；伙伴脸部中心映射至画面横坐标 302、脸部上沿 181、脸高 167。整个伙伴人物使用同一个缩放和平移，没有对伙伴单独换头、调颈或改变身体宽度。

## 玩家身体处理与伙伴检查

既有玩家身体资源去除灰白背景，包括手臂围成的封闭空隙。轮廓做了约一个源像素的收缩、边缘颜色去污染及透明度过渡。颈部明亮皮肤被单独保护，已修复把亮色反光误删为背景导致的领口透明孔。男性整片衣领纳入服装调色，同时保护皮肤和纹身；女性调色以红衣布料色相为依据，避免染到手臂和手。

已查看所有素材的深色背景拼图、放大的男性衣领和服装蒙版，以及咖啡馆实景中的透明边缘。服装变体另以皮肤蒙版恢复原肤色，保留皮肤纹理。样例头像 `public/assets/sample-player.jpg` 从已有样例文件转换，为 1024 × 768 的 JPEG。

伙伴连贯人物经整张透明图与咖啡馆实际免费合影人工检查，头颈肩自然衔接。玩家身体仍来自较小的参考视图，放大后不会增加真实细节；原长发移除后的玩家肩部衔接仍依赖上传头像匹配与微调。用正脸、光线均匀的玩家头像更容易与身体衔接。
