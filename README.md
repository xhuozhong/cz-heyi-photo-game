## 费用与照片

免费模式使用浏览器内的 MediaPipe 人脸定位与人物分割，再用 Canvas 拼合原照片像素和模板。免费模式的玩家头像不上传，不调用图片生成服务，不消耗 LibTV 或 ChatGPT 生图额度。

付费模式启用后，玩家同意将照片上传至服务方后端与 LibTV，生成会消耗运营方的 LibTV 额度。玩家使用自己的钱包付款，无需共享运营方账号。订单凭证保存在当前浏览器；清理站点数据前应保存订单号与交易哈希。

相册仅保存在当前浏览器，最多12张；下载图片带“合成合影”标记，不代表真实见面。签名是娱乐用途的纪念装饰，不代表本人现场签署。免费模板在脸部下方的右下角放置签名，既有合成标记保留；AI 结果在领取时由浏览器追加底部签名区域，原图人物和水印完整保留，重新领取始终从服务器原图处理一次，不重复加盖。升级前已收藏的照片保持原样。

## 本机运行

免费静态服务需要 Node.js 20 或更新版本，无需安装第三方 npm 依赖。付费服务器推荐 Node.js 24，先按部署说明安装固定依赖。

运行 `npm start`，打开 <http://127.0.0.1:4175>；Windows 也可以双击 `start-game.cmd`。`PUBLIC_PORT` 可修改端口。

默认静态服务只监听本机，支持 GET/HEAD，没有账号、上传或生成 API。要部署在线游戏，发布 public 目录中的全部文件即可；托管服务需支持 .mjs、.wasm 和 .tflite 静态文件。

## GitHub Pages 发布

公开仓库使用 GitHub Pages 托管。仓库 Settings → Pages → Source 选择 GitHub Actions。`.github/workflows/pages.yml` 将 `public/` 作为完整静态网站发布；修改游戏后推送到 `main` 会自动更新在线版本，也可在 Actions 手动运行。

免费游戏资源使用相对路径，可从 `/cz-heyi-photo-game/` 项目子路径加载，无需外部生图服务或部署密钥。付费服务器不运行在 GitHub Pages 上。

## 文件

- public/index.html、styles.css、app.js：交互界面、设置、合影和相册。
- public/template-compositor.js：头像分割、对齐、调光、身体肤色匹配与模板合成。
- public/signature-stamp.js、public/assets/signatures/：对应人物签名加载、模板盖印及 AI 原图底部纪念签名合成；浏览器本地处理，不消耗生成额度。
- public/assets：人物参考、身体/衣服/皮肤蒙版、实拍场景与虚构示例头像。
- public/vendor/mediapipe：固定版本1.0.1的运行库、模型、WASM、LICENSE和校验清单。
- static-server.mjs：本机静态入口。
- public/paid-mode.js、paid-config.js：付费 UI、钱包流程和订单恢复。
- backend/：链上核验、私有订单持久化、图片处理和官方 LibTV CLI 接入。
- deploy/、.env.example、DEPLOYMENT.md：独立服务器启动与部署配置。

本仓不包含账号凭据、私有订单、生成任务数据、日志或玩家上传照片。
