## 费用与照片

免费模式使用浏览器内的 MediaPipe 人脸定位与人物分割，再用 Canvas 拼合原照片像素和模板。免费模式的玩家头像不上传，不调用图片生成服务，不消耗 LibTV 或 ChatGPT 生图额度。

AI 模式需玩家同意将照片上传至服务方后端与 LibTV，首次免费和后续付费生成都会消耗运营方的 LibTV 额度，并受到同一生成预算限制。玩家使用自己的钱包签名或付款，无需共享运营方账号。新订单和首次免费授权都需通过服务端人机验证；免费资格同时受钱包、浏览器标识与访客网络限制。试运行全站每天最多 5 次、累计 20 次免费，同一访客 IP 每天最多 2 次，以北京时间计日；历史已使用免费次数计入累计上限。免费名额不足时明确暂停首次免费，不自动转成付费订单。钱包、浏览器和 IP 无法证明自然人唯一身份，但全站上限可限制额度消耗。订单凭证保存在当前浏览器；清理站点数据前应保存订单号与付费交易哈希。失败或提交状态不确定的首次免费订单保留原订单恢复路径，不自动恢复一次新的免费资格，以免重复消耗额度。

相册仅保存在当前浏览器，最多12张；下载图片带“合成合影”标记，不代表真实见面。签名是娱乐用途的纪念装饰，不代表本人现场签署。免费模板在脸部下方的右下角放置签名，既有合成标记保留；AI 结果在领取时由浏览器追加底部签名区域，原图人物和水印完整保留，重新领取始终从服务器原图处理一次，不重复加盖。升级前已收藏的照片保持原样。

## 本机运行

免费静态服务需要 Node.js 20 或更新版本，无需安装第三方 npm 依赖。付费服务器推荐 Node.js 24，先按部署说明安装固定依赖。

运行 `npm start`，打开 <http://127.0.0.1:4175>；Windows 也可以双击 `start-game.cmd`。`PUBLIC_PORT` 可修改端口。

默认静态服务只监听本机，支持 GET/HEAD，没有账号、上传或生成 API。要部署在线游戏，发布 public 目录中的全部文件即可；托管服务需支持 .mjs、.wasm 和 .tflite 静态文件。

本机 AI 后端对 `public/vendor/` 和 `public/assets/` 中成功的 GET/HEAD 响应允许缓存一小时，以减少模型和素材重复经过 Tunnel 下载。vendor 的 WASM、TFLite 和 JS/MJS 仅在客户端明确接受 gzip 时由源端压缩；图片不重复压缩。压缩结果仅缓存于内存，总上限 16 MiB，并在源文件修改时间或大小变化后失效。HTML、`paid-config.js`、全部 API 和玩家私有结果始终 `no-store`，不进入公共压缩缓存。

## GitHub Pages 发布

公开仓库使用 GitHub Pages 托管。仓库 Settings → Pages → Source 选择 GitHub Actions。`.github/workflows/pages.yml` 将 `public/` 作为完整静态网站发布；修改游戏后推送到 `main` 会自动更新在线版本，也可在 Actions 手动运行。

免费游戏资源使用相对路径，可从 `/cz-heyi-photo-game/` 项目子路径加载，无需外部生图服务或部署密钥。`public/paid-config.js` 指向 `https://xhuozhong.com`，AI 请求与照片只发往该 HTTPS 后端；GitHub Pages 不运行付款核验或生图进程。后端须允许 `https://xhuozhong.github.io` 的跨域请求，浏览器会先核验服务、费用和免费资格再请求钱包签名或付款。本机服务不可达时显示暂停提示，免费模板、微调、签名、下载与相册继续运行。
